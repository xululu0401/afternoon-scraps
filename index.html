一下午都是边角料

一下午三个小时，被消息、电话、同事各打断几次，加起来也没耽误多久，可就是凑不出一整段能写东西的时间。填一句话：多长、被打断几次、每次耽误多久、想要多长一整段，它算出这样的下午里，切出来的最长一段平均多长、有多大机会凑出你要的那一段，以及少打断一次、回神快一点、拉长时间分别能换回多少。

      怎么算的、算不了什么

      假设：每次打断落在哪一刻互相独立、哪一刻都一样可能；每次打断连回神吃掉固定的一段时间。把吃掉的时间拿走，剩下能用的时间被打断点随机切成「打断次数 + 1」段。

      公式：剩下 L′、切成 n 段时，从短到长第 i 段平均长 L′/n ×（1/(n−i+1) + … + 1/n），最短一段平均只有 L′/n²；最长一段 ≥ x 的概率 = 1 − Σ(−1)ʲ·C(n,j)·(1 − j·x/L′)ⁿ⁻¹（括号小于 0 的项去掉）。「有把握拿到的最长一段」是让这个概率刚好等于你填的把握的那个长度，向下取到 0.1。

      真实的打断常常扎堆（开会前后、午饭后），也可能你自己会挑时间回消息，这时结果会和随机模型不一样。它只说明「打断次数和回神时间」这两件事本身有多大影响，不预测你明天的日程。默认例子的数字是虚构的。单位可以换成别的（厘米、页），算法不变。
